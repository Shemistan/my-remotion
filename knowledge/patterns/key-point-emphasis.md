# Выделение ключевой мысли

«Главное —», «запомните», «вывод», «итог», цитата, тезис. Один элемент в
кадре, всё остальное подчинено ему. Темп замедляется; появление —
заметное, но без суеты.

## Визуальные приёмы

1. **Крупный заголовок с эффектом появления** — по словам, blur-in,
   slide-up.
2. **Подсветка маркером / underline** — фраза подчёркивается по кадру.
3. **Карточка-цитата** — рамка, свечение границы, тень.
4. **Lower third / плашка** — вывод в нижней трети поверх сцены.
5. **Зум на элемент** — камера наезжает (Ken Burns, Scene3D step).
6. **Счётчик-акцент** — одна цифра на весь экран.

## Как выбирать

- Текст → `text-animation` с одним эффектом; не смешивать два.
- Цитата/тезис в рамке → border-beam, shine-border, glow-card
  (`lists-grids-stagger`/`icons-shapes`).
- На фоне идущего видео → lower third (`layout-templates`).
- Нужно «подчеркнуть» в уже показанном тексте → highlighter/underline.
