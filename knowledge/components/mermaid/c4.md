# C4 diagram (experimental) — `mermaid/c4`

| Поле | Значение |
|---|---|
| Репозиторий | `mermaid` (`templates/infografika/mermaid`) |
| Вид | diagram-type, экспериментальный (по доке) |
| Категория | `diagrams-flow` |
| Совместимость с Remotion | complex |
| Флаги | `svg`, `dom`, `engine:d3`, `async-data` |
| Проверка | static-review |
| Лицензия | MIT (LICENSE, package.json) |

## Что визуализирует

C4-модель: люди и системы в виде карточек с названием и описанием, границы
(Enterprise/System Boundary), связи `Rel`/`BiRel` с подписями. Уровни:
Context, Container, Component, Dynamic, Deployment.

## Когда использовать

Архитектура ПО по уровням C4, синтаксис совместим с PlantUML. Для
инфраструктуры с иконками — `mermaid/architecture`.

## Фразы из озвучки

- «клиент банка работает с системой интернет-банкинга»
- «система отправляет письма через внешний почтовый сервис»
- «внутри границы банка — три системы»

## Визуальный стиль

Синие карточки систем и людей, серые для внешних элементов.
Корпоративный архитектурный вид.

## Входные данные

Текстовый DSL (сокращено из `docs/syntax/c4.md`):

```
C4Context
  title System Context diagram for Internet Banking System
  Person(customerA, "Banking Customer A", "A customer of the bank")
  System(SystemAA, "Internet Banking System")
  BiRel(customerA, SystemAA, "Uses")
```

Также `C4Container/C4Component/C4Dynamic/C4Deployment`, `*_Ext`,
`SystemDb`, `SystemQueue`, `Boundary(…){…}`,
`UpdateElementStyle`/`UpdateRelStyle`. Конфиг `c4` передаётся через
`renderer.setConf`, плюс глобальный `wrap`.

## Анимации

Своей анимации нет. По кадру: границы, затем элементы, затем связи.

## Совместимость и адаптация

`complex`. Общий рецепт — `compatibility/mermaid.md`. Специфика: свой
рендерер, элементы раскладываются рядами. Классы элементов сверить по
готовому SVG. Длинные описания переносятся по замеру текста, поэтому
шрифт загружается до render.

## Паттерны

`system-structure`, `relationships`
