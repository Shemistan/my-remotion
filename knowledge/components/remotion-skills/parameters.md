## Когда использовать

Один шаблон выпускается с разными текстами, числами, цветами; пропсы
редактируются в Studio и подставляются при рендере по данным. Установка
`zod` по найденному lockfile (npm/bun/yarn/pnpm), затем `schema` на
`<Composition>`.
