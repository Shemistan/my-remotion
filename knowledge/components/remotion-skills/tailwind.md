## Когда использовать

Если Tailwind установлен — им можно и нужно пользоваться для вёрстки. Классы
`transition-*` и `animate-*` запрещены: анимация только через
`useCurrentFrame()`. Важно при переносе компонентов из Tailwind-библиотек.
