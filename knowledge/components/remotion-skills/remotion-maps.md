## Что визуализирует

Не рисует; документ-развилка по картам: выбрать **одну** технику по кадру и
загрузить только её `TECHNIQUE.md` (каталоги техник самодостаточны).

## Когда использовать

В озвучке география. Выбор:

| Техника | Когда |
|---|---|
| `remotion-skills/maps-static` | карта — лишь контекст места |
| `remotion-skills/maps-mapbox` | есть токен Mapbox, нужны стили, глобус, 3D-здания |
| `remotion-skills/maps-maplibre` | бесплатно, без ключа, без 3D-зданий |
| `remotion-skills/maps-maptiler` | аннотации поверх географии: границы, реки, подписи |
| `remotion-skills/maps-cesium` | 3D-пролёт над рельефом/городом |
