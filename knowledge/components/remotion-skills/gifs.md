## Что визуализирует

Не рисует; документ о GIF, APNG, AVIF и WebP, синхронных с таймлайном.

## Когда использовать

Вставить мем, анимированный стикер, короткую гифку так, чтобы она шла по
кадрам Remotion, а не по часам браузера: `<AnimatedImage src width height>`
из `remotion`; удалённые URL — только с CORS; `@remotion/gif` — если рендер
не в Chrome.
