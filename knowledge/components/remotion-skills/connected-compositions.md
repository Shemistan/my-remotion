## Что визуализирует

Не рисует; документ о связанных композициях — сцене или карточке, которую
можно открыть в собственной временной шкале Studio и править там же, где её
использует родитель.

## Когда использовать

Крупная сцена, переиспользуемая карточка, группа «стикер + звук», итоговая
графика. Шаги: экспорт через `Interactive.create()` (`layout:
'absolute-fill'` для сцены, `'none'` для элемента) → рендер в родителе с
inline-пропсами → регистрация **той же** ссылки в `<Composition
component={…}>` с уникальным id и `defaultProps`. Компонент не должен
зависеть от родителя (шрифты, фон). Проверять оба вида.

## Фразы из озвучки

- «эта карточка повторится несколько раз»
- «отдельная заставка в начале»
- «итоговый слайд со сводкой»
