# my-remotion

## AI Motion Studio

```
make run      # запуск: http://127.0.0.1:8790 (Ctrl+C — стоп)
make doctor   # проверка окружения и хранилища
make check    # все проверки репозитория
```

Хранилище — `/Volumes/External SSD/moution-studio-materials/store` (SSD должен быть подключён);
своё — `MS_DATA_DIR=… make run`. Подробности — `app/motion-studio/README.md`.
