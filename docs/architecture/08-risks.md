## 2. Лицензии и условия использования (сверено 2026-10-20)

Характер использования (подтверждено человеком): персональный инструмент, один
пользователь, локальный запуск на своём Mac, без коммерческого использования,
публичного доступа, SaaS и облака.

### 2.1. Remotion

Источник: `LICENSE.md` в `remotion-dev/remotion` (ветка `main`, прочитан 2026-10-20).

- [Ф] Free License доступна, если вы «an individual», «a for-profit organization with
  up to 3 employees», некоммерческая организация или оцениваете Remotion без
  коммерческого использования.
- [Ф] Free License разрешает использование «non-commercially or commercially for the
  purpose of creating videos and images».
- [Ф] Запрещено копировать или модифицировать код Remotion для продажи, сдавать в аренду,
  лицензировать и сублицензировать производные.
- [Ф] «In Remotion 5.0, the license will slightly change».

**Вывод:** личный некоммерческий проект частного лица подпадает под Free License.
Ограничения для нас: не распространять и не продавать модифицированный Remotion
(не планируется). Перед переходом на Remotion 5.x — повторная сверка лицензии.
Это прочтение текста лицензии, а не юридическая консультация.

### 2.2. Claude Code

Источник: https://code.claude.com/docs/en/legal-and-compliance (прочитано 2026-10-20).

- [Ф] Для Free/Pro/Max действуют Consumer Terms, использование подчиняется Anthropic
  Usage Policy.
- [Ф] «OAuth authentication is intended exclusively for purchasers of Claude Free, Pro,
  Max, Team, and Enterprise subscription plans and is designed to support ordinary use
  of Claude Code and other native Anthropic applications».
- [Ф] Запрещено сторонним разработчикам предлагать вход Claude.ai в своих приложениях,
  направлять запросы через подписку «on behalf of their users», собирать, хранить или
  передавать учётные данные и токены Claude.ai.
- [Ф] Явно не ограничено: «an end user signing in to the unmodified Claude Code binary
  with their own Claude subscription».
- [Ф] «Advertised usage limits for Pro and Max plans assume ordinary, individual usage of
  Claude Code and the Agent SDK».
- [Ф] Разработчикам продуктов, в том числе на Agent SDK, рекомендована аутентификация по
  API-ключу.

**Вывод:** Motion Studio запускает неизменённый `claude` от имени того же пользователя,
который вошёл в CLI штатным способом; токены приложение не читает и не хранит, другим
людям доступ не даёт. По нашему прочтению это допустимо. **Нерешённое:** документ
не описывает явно, где граница «ordinary, individual usage» для автоматизированных
локальных вызовов. Меры: лимит 2 параллельных агента, бюджет на сцену, без фоновых
циклов без участия пользователя. Если появятся сомнения или ограничения от Anthropic —
переход на API-ключ (`04` §5) без изменения архитектуры. Agent SDK использовать только с
API-ключом.
