## Утверждённые решения (2026-10-20)

| # | Решение | Где |
|---|---|---|
| 1 | Отдельное приложение `my-remotion/app/motion-studio/`; ai-platform — только независимые сервисы (ASR, изображения) через адаптеры; код ai-platform не меняется | ADR 0001, `03` §1 |
| 2 | Старый `aiplatform/motion/` полностью исключён из референсов | `01` §3.2а |
| 3 | Персональный локальный инструмент: один пользователь, Mac, `127.0.0.1`; без авторизации, ролей, биллинга, облака | ADR 0005, `03` §6 |
| 4 | Данные на внешнем SSD, путь только через `MS_DATA_DIR`, проверка диска перед задачами, без тихого переключения на системный диск | ADR 0006, `03` §5 |
| 5 | Claude Code — агентный runtime при соответствии правилам Anthropic; Opus — Motion Director и Engineer, Sonnet — остальные; модели и лимиты в настройках; $5 на сцену — ориентир для тестов, не лимит подписки | ADR 0003, `04` §5, `08` §2 |
| 6 | Remotion — по бесплатной лицензии для частного лица (личный некоммерческий проект), версия 4.x с точным pin | ADR 0004, `08` §2 |

Рекомендуемое значение `MS_DATA_DIR` для этой машины (не значение по умолчанию):
`/Volumes/External SSD/MotionStudio` (диск
подключён, APFS, свободно 211 ГБ; рядом, но отдельно от `local_models`). Каталог
создаётся при первом запуске `doctor --init` после подтверждения.

Неблокирующие значения по умолчанию (меняются в настройках): порт `127.0.0.1:8790`;
Node 22; 3 стилевых пресета; превью в половинном разрешении; лимит 2 автоисправления.
