# Руководство по AI Motion Studio

Это руководство для автора YouTube-видео. Оно ведёт от установки до готового MP4. Команды нужны только для запуска. Вся дальнейшая работа идёт в браузере.

Motion Studio работает с тремя видами проектов:

- **Сцены** — отдельная моушн-сцена по короткому описанию.
- **Сценарий** — текст ролика, разбитый на будущие моушн-сцены.
- **Видео** — исходный ролик, монтаж, графика поверх него и финальный экспорт.

Скриншоты сделаны на тестовых данных. Личных видео на них нет.
