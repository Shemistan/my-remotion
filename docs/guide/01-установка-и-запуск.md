# 1. Установка и запуск

## Что это

Motion Studio — локальное приложение для Mac с Apple Silicon. Интерфейс открывается в браузере, а файлы проекта остаются на вашем компьютере. Рабочее хранилище находится на внешнем SSD:

`/Volumes/External SSD/moution-studio-materials/store`

Хранилище — это папка с проектами, базой данных, промежуточными файлами и экспортами. Приложение не подменяет её папкой на системном диске, если SSD отключён.

## Когда нужно

Эти шаги нужны при первой установке, после переноса на другой Mac и когда приложение перестало запускаться.

## Шаги

1. Подключите внешний SSD. Проверьте, что на нём есть папка `moution-studio-materials`.
2. Установите Xcode Command Line Tools командой `xcode-select --install`, если они ещё не установлены.
3. Установите Claude Code и выполните `claude login`.
4. Откройте Terminal и перейдите в папку репозитория.
5. Выполните:

   ```sh
   make setup
   ```

   Установка проверит Mac, SSD и вход в Claude. Затем она поставит Node, ffmpeg, окружение распознавания речи, npm-пакеты и браузер рендера. На новом компьютере это обычно занимает 10–20 минут и требует сети.

6. Запустите приложение:

   ```sh
   make run
   ```

7. Откройте `http://127.0.0.1:8790`.
8. Для остановки вернитесь в Terminal и нажмите `Ctrl+C`.

## Частые проблемы

**SSD не найден.** Подключите диск и убедитесь, что путь написан именно как `/Volumes/External SSD/moution-studio-materials/store`.

**Установка сообщает, что Claude не готов.** Выполните `claude login`, затем повторите `make setup`.

**Приложение не открывается.** Выполните проверку окружения `make doctor`. Она проверяет зависимости, хранилище, свободное место и браузер рендера.

**Порт занят.** Остановите прежний запуск Motion Studio. Приложение слушает только локальный адрес `127.0.0.1`.

**После запуска сразу пошли задачи.** Незавершённая очередь восстанавливается автоматически. Откройте раздел «Задачи» и отмените ненужное. Перед работой с чужой копией хранилища сначала проверьте очередь.
