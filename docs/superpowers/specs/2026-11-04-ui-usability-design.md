# Юзабилити UI студии: упавшие задачи, сцены, мелочи

Повод: 22 генерации в Map Go упали на лимите Claude. Найти их и повторить через UI
оказалось почти невозможно. Обход интерфейса 2026-11-04 дал 12 замечаний, все в работе.

## 1. Задачи и повтор

- **Подробнее под строкой.** Карточка задачи раскрывается строкой таблицы сразу под
  выбранной задачей (`<tr><td colSpan>`), а не после всей таблицы.
- **Причина ошибки в строке.** Колонка «Ошибка» показывает суть: заголовок этапа и
  короткую причину из `error.message`. Известные причины переводятся: лимит подписки
  Claude/Codex («hit your … limit», «usage limit», «rate limit») превращается в
  «Закончился лимит Claude — сброс в 19:00», если время есть в тексте.
- **Повтор пачкой.** `POST /api/jobs/retry-failed` с `{ project_id?, scene_id? }`
  повторяет все `failed` задачи в области через существующий `retryJob`. Ответ:
  `{ retried: id[], skipped: [{ id, code }] }`. Кнопки «Повторить все упавшие (N)» есть
  на «Задачах» (с учётом фильтра проекта) и в проекте.
- **Фильтр и объём.** На «Задачах» фильтр по проекту. Список приходит порциями по 50 с
  кнопкой «Показать ещё». В строке показаны проект и название сцены, а не голое «сцена».
- **Главная.** Блок «Активные задачи» показывает число упавших задач за 24 ч со
  ссылкой на «Задачи» с фильтром «ошибка».

## 2. Проект и сцена

- **Обложка.** `GET /api/versions/:id/poster.png` отдаёт кадр с наименьшим номером из
  `frames/` версии (404, если кадров нет). Карточки сцен берут его вместо `frames/0.png`.
- **Различимые названия.** В DTO сцены проекта добавлено поле `excerpt`: промпт без
  общего для сцен проекта префикса, обрезанный по слову до 120 символов. Карточка
  показывает его второй строкой, если название не уникально в проекте. Сцену можно
  переименовать: `PATCH /api/scenes/:id { title }`, поле редактируется в заголовке
  страницы сцены. Новые сцены принимают необязательный `title` при создании.
- **Видимость сбоя.** В DTO сцены есть `last_job` (последняя задача сцены: id, status,
  error). Карточка упавшей сцены получает красный бейдж «ошибка» и причину. Над сеткой
  стоит фильтр «все / упавшие / готовые». На странице сцены без версий, если последняя
  задача упала, вместо «пока нет версий» показан `JobStatus` с кнопкой «Повторить».

## 3. Мелочи

- «Последние экспорты» на главной: в каждой строке проект и сцена.
- «Новый проект»: поле названия на всю ширину, подсказка «Сначала введите название»
  выводится один раз под полем.
- «Настройки»: роли подписаны по-русски, теми же ярлыками, что в «Затратах». Модель
  выбирается из списка (`sonnet`, `opus`, `haiku`) с возможностью ввести свою (datalist).
- «Диагностика → Проверка окружения»: строка Codex CLI с версией или причиной
  недоступности (`CodexRuntime.capabilities`).

## Вне рамок

Автоповтор задач после сброса лимита; переработка Playground-чата.
