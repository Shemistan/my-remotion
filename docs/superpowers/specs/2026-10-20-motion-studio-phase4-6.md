# Motion Studio: Phase 4–6 (сцены проекта, сборка, полировка)

Пакетная генерация сцен проекта на едином Remotion-движке, Scene Inspector, утверждение C; таймлайн и финальный рендер с проверкой; управление проектами, диагностика, производительность, качество анимации, руководство.

Спецификация — `AI_Motion_Studio_TZ.md` v1.2 и архитектура Phase 0 (`docs/architecture/`,
ADR 0001–0007), утверждённые человеком 2026-10-20; полная реализация Phase 1–6 поручена
человеком 2026-10-20. Решения контроллера по пробелам спеки перечислены в плане
(раздел «Противоречия и пробелы»), выбраны значения по умолчанию.

## Изменения 2026-10-25

После сценарного трека (S1–S18) человек 2026-10-25 принял решения Р-V1…Р-V9 («Согласен с твоими
рекомендациями»); они записаны в ADR 0009 «Видеосцены через сценарный конвейер»
(`docs/decisions/0009-video-scenes-via-script-pipeline.md`), план переписан (редакция 2026-10-25).

- **Р-V1.** Сцены видеопроекта генерируются `playground.generate`/`playground.edit` с новым входом
  `video` рядом со `script`; `production.*` и `runScenePipeline` не делаются.
- **Р-V2.** Пакет сцен — набор обычных задач с ключами `video:<plan>@r<rev>:<item>:s<style>[:try-n][:regen-k]`
  (как `server/src/script/batch.ts`), не задача `production.batch`; нужно валидное Approval B.
- **Р-V3.** Хранение — новые таблицы `video_scenes`, `video_batches` (и `video_packages`,
  `video_timelines`) по образцу `script_*`; `script_*` не обобщаются. Одна миграция `006`.
- **Р-V4.** Approval C — на версию сцены: `scene:<id>@r<номер версии>` + хеш манифеста; final —
  `timeline:<id>@r<N>` + хеш настроек экспорта; отзыв и поиск — по субъекту (`subject_key`), а не по
  всем решениям вида в проекте; таблица `approvals` пересобирается миграцией.
- **Р-V5.** Все размещения рендерятся на весь кадр: `fullscreen` — непрозрачно, остальные — прозрачно,
  графика только в `layout.rect` (необязательное поле `ScenePropsBase`); при лице в центре кадра
  `split_screen` не предлагается (без перекадрирования автора).
- **Р-V6.** Длительность видеосцены меняется только через план (границы по словам → пересборка сцены
  с новой плановой длиной); retime с таймлайна в обход блокировки S16a не делается.
- **Р-V7.** Бюджетного гейта пакета нет (стоимость справочная, Р10 сценарного трека).
- **Р-V8.** Task 50 заменяется треком качества (S16b + ночные прогоны), последним; motion-kit — от
  0.5.8, следующая 0.5.9.
- **Р-V9.** Сначала Phase 5-lite — папка клипов видеопроекта (MP4 + ProRes 4444 с альфой +
  шпаргалка с таймкодами исходника и смонтированного ролика) через механизм `script.package`/`exportOne`;
  затем полная Phase 5.

Противоречия и пробелы F4, F7, F11, F12 плана редакции 2026-10-21 заменены этими решениями; F1–F3,
F5, F6, F8–F10, F13, F14 действуют с уточнениями плана.
