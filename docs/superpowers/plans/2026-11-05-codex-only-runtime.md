# Codex-only: план реализации

**Goal:** дать в настройках явный режим `codex-only`, в котором ни один вызов
не уходит в Claude, и подготовить воспроизводимый A/B-контур для доводки качества.

- [x] **T1. Контракт конфига** — три runtime-режима, миграция старой делегации,
  поролевые профили Codex; тесты валидации и совместимости.
- [x] **T2. Маршрутизатор** — живая смена режима, полное покрытие Codex и запрет
  фолбэка в `codex-only`; regression-тесты гибридных предохранителей.
- [x] **T3. API и UI** — `agentRuntime` в settings DTO/PUT, переключатель Claude / Hybrid /
  Codex only, фактические доли и явное предупреждение об отсутствии fallback.
- [x] **T4. Bench** — `--runtime`, boot-override, runtime и Codex-профили в provenance,
  запрет смешивать runtime в одном прогоне; обновить `BENCH.md`.
- [x] **T5. Проверка и передача** — точечные unit/UI-тесты, `./check`, ревью diff,
  коммит в отдельной ветке.
