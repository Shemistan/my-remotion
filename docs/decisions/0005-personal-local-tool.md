# Персональный локальный инструмент без облака и многопользовательности

**Контекст.** Человек подтвердил: AI Motion Studio — только для личного использования,
один пользователь, запуск локально на своём Mac, без коммерческого использования,
публичного доступа, SaaS и облачного деплоя; все материалы хранятся локально.
Внешние LLM через Claude Code допустимы, полный офлайн не нужен.

**Решение.** Сервер слушает только `127.0.0.1`. Нет авторизации, ролей пользователей,
биллинга, облачного хранения и облачной инфраструктуры. Сохраняются SQLite, локальный
workspace и работа без облачных сервисов, кроме вызовов LLM. Проверка `Host`/`Origin`
остаётся как защита локального сервера от чужих веб-страниц в браузере (DNS rebinding,
CSRF), а не как авторизация.

**Последствия.** Архитектура проще: один процесс, одна БД, без сетевой поверхности
наружу. Многопользовательский или удалённый режим потребует отдельного решения и
пересмотра безопасности. Remotion используется по Free License (ADR 0004).
