# Remotion 4.0.537 с точным pin и собственный motion-kit

**Контекст.** В источниках KB версии Remotion от 4.0.200 до 4.0.537; официальные skills
описывают API 4.0.537; разные `@remotion/*` нельзя смешивать. Из 836 записей KB
Remotion-native компонентов 23, ни одна запись не отрендерена; React-библиотеки
построены на времени, а не на кадрах.

**Решение.** Render-пакет закрепляет все `remotion`/`@remotion/*` точно на 4.0.537.
Создаём motion-kit — небольшую библиотеку frame-driven примитивов по мотивам
MIT-исходников KB с provenance. Сгенерированные сцены собираются из kit; код из KB
адаптируется, только если в kit нет подходящего.

**Последствия.** Детерминизм и единый визуальный язык; первые реальные
`rendered-ok` для записей KB. Обновление Remotion — отдельная задача с
перерендером эталонных сцен. Kit нужно развивать по мере новых паттернов.
