# Агенты через `claude -p --restricted` без Bash

**Контекст.** ТЗ §10 требует запуска Claude Code в отдельном каталоге, типизированного
выхода, лимитов и запрета bypass permissions. В Phase 0 проверено на CLI 2.1.304:
`--output-format json --json-schema` даёт `structured_output`, стоимость и модель;
`--restricted` ограничивает файловые инструменты рабочим каталогом, отключает Bash
и запрещает bypass; попытка чтения `~/.zshrc` отклонена.

**Решение.** `ClaudeCodeRuntime` запускает `claude -p --restricted --strict-mcp-config
--tools <минимум для роли> --output-format json --json-schema <схема>
--no-session-persistence --max-budget-usd <лимит>` с cwd = draft-каталог версии.
Агенту не дают Bash: typecheck, проверка и рендер выполняет оркестратор, ошибки
возвращаются агенту структурированно. Исходники из KB копируются в `refs/` до запуска.

**Последствия.** Агент не может выполнить произвольную команду или прочитать чужие
файлы. Цикл «исправить по ошибке компиляции» идёт через оркестратор и стоит отдельного
вызова. Зависимость от формата JSON CLI — проверяется в `doctor` и интеграционным тестом.
