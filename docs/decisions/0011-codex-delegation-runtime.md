# Codex CLI — второй рантайм агентов с регулируемой долей

**Контекст.** Вызовы Claude Code — самый дорогой ресурс студии: engineer ≈ 62 % стоимости,
motion_director ≈ 27 %, visual_qa ≈ 10 %. У пользователя есть вторая подписка — Codex.
ADR 0003 разрешает агентам только файловые инструменты (`claude -p --restricted`) и
закладывает замену рантайма через `AgentRuntimeAdapter`.

**Решение.**

1. `CodexRuntime` (`server/src/agents/codex.ts`) — `codex exec --json --ephemeral` со
   строгой JSON Schema ответа, промпт через stdin. Журналы, TMPDIR, реестр процессов,
   таймаут и отмена — общие с `ClaudeCodeRuntime`.
2. `RoutingRuntime` (`server/src/agents/routing.ts`) решает для каждого вызова, кто его
   выполняет. Решение зависит от доли роли из `delegation.level` и детерминированного
   хеша вызова. Предохранители: visual_qa, исправления и повторные попытки — всегда
   Claude; упавший вызов Codex сразу перезапускается в Claude (у engineer — после восстановления
   черновика из снимка); роль, у которой
   «чистота» хуже Claude больше чем на 15 п. п., встаёт на авто-паузу.
3. Политика (`delegation.*`) меняется из UI и действует сразу; `codex.bin` — только в
   config.json (как `claudeBin`).

**Отступление от ADR 0003.** У Codex есть shell. Он работает в песочнице Codex (macOS
Seatbelt): сети нет, запись только в cwd (`workspace-write` у engineer, иначе
`read-only`), читать можно весь диск. Это приемлемо для личного локального инструмента
(ADR 0005). По умолчанию делегирование выключено.

**Дополнение 2026-11-05: режимы рантайма** (спека `2026-11-05-codex-only-runtime-design.md`).
`agentRuntime` выбирает один из трёх режимов; п. 2 и 3 выше описывают `hybrid`.

- `claude-code` — все вызовы в Claude; `hybrid` — доля Codex со всеми предохранителями п. 2.
- `codex-only` — все вызовы в Codex без фолбэка, включая visual_qa, исправления и повторы.
  Это осознанное исключение из правила «судья не совпадает с исполнителем»: режим нужен,
  когда лимит Claude исчерпан, и цена исключения — более слабая независимость оценки сцены.
  Сбой Visual QA по-прежнему не даёт версии стать готовой.
- Исходы `codex-only` не пишутся в статистику чистоты: они не должны ставить роли `hybrid` на
  авто-паузу.
- Промпты ролей написаны под инструменты Claude: `codexToolsNote` переводит их для Codex, `Read`
  для картинок — `view_image`. Без перевода Codex отказывался открывать кадр. В `--json` события
  `view_image` нет, поэтому открытие кадров по журналу не проверить: только по содержанию ответа.
- Качество `codex-only` пока не подтверждено: нужен реальный прогон, где замечания Visual QA
  сверены с роликом, и A/B бенчмарком.

**Последствия.**

- В `agent_runs` прогоны Codex имеют модель `codex:<model>` и стоимость 0. Веса ролей
  считаются только по вызовам Claude.
- Безопасный максимум без motion_director ≈ 63 %, с ним ≈ 90 %. Калибровка бенчмарком —
  после живых прогонов.
- Состояние авто-паузы и окна статистики хранится в `$MS_DATA_DIR/delegation-state.json`.
