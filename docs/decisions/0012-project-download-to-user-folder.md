# Скачивание роликов проекта в папку, которую указал человек

**Контекст.** Человек хочет выбрать ролики в окне проекта и скачать их в свою папку, например на
SSD. Правило S18 велит приложению писать на SSD только в `moution-studio-materials/`. Готовых
файлов обычно нет: у сцены есть только превью половинного разрешения (scale 0.5, CRF 23), а
экспорт появляется по запросу. Браузерная загрузка не годится: она не выбирает папку и теряет
файлы при закрытии вкладки.

**Решение.** Задача `project.download` (миграция 008) на сервере: для выбранных сцен берёт готовый
экспорт полного качества или рендерит его, затем копирует файл в папку. Папку человек указывает
сам: системное окно `osascript choose folder` или путь вручную.

- Явно выбранная папка назначения — исключение из S18: это не данные приложения, а выдача
  человеку. `assertSsdWriteAllowed` здесь не применяется.
- Внутрь хранилища (`MS_DATA_DIR`) копировать нельзя: сервер отказывает.
- Копия идёт через `.part`, сверяется по sha256 и только потом получает имя. Чужие файлы не
  перезаписываются: копия получает суффикс `_2`. Файл с тем же содержимым не копируется повторно,
  поэтому повтор задачи безопасен.
- Роуты защищены общей проверкой Origin (ADR 0005): чужая страница не откроет окно и не поставит
  задачу. Путь для Finder берётся только из входа задачи в БД.

**Последствия.** Новый тип задачи требует пересборки таблицы `jobs`. Выбор папки через системное
окно работает только на macOS, на других системах остаётся ввод пути. Финальные экспорты
видеопроекта в список не входят: сейчас выбираются только сцены.
