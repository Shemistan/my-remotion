## Находки (дефекты продукта, не исправлялись)

- **D1 (важно, шаг 3).** Финал с fps ≠ `timeline_fps` (25 при 30): кадры исходника после вырезок
  стоят на 1–2 кадра раньше ожидаемого `verifyFinal` → экспорт 25 fps этого проекта всегда
  `failed_verification` (3 из 3). Звук синхронен. Предположение (не проверено): пересчёт
  последовательностей `clipsToSequences({ ...tl, fps: out.fps })` в `server/src/final/render.ts`
  округляет границы вырезок к сетке 25 fps иначе, чем `outFrame`/`sourceFrameAt` проверки.
- **D2 (важно, шаг 5б).** При `storage_offline` (каталог хранилища переименован) процесс финала
  создаёт `<MS_DATA_DIR>/run/tmp` по старому пути; при отключённом SSD это была бы запись на системный
  диск (`/Volumes/…`). Вероятно — воркер рендера с `TMPDIR` в `run/tmp` хранилища, не остановленный при
  offline. Нарушает ADR 0006.
- **D3 (вопрос к брифу).** `sampleVerifyFrames(n = 12)` берёт 6 кадров вне сцен + середины сцен (до
  6): при 3 сценах — 9 кадров, бриф Step 2 говорит «12 кадров». Проверка приёмки считает по правилу
  выборки.
- **D4 (наблюдение).** Новый запрос финала с другими настройками отзывает прежнее решение final
  (T4.23: решение 1080p `revoked`); история экспортов этого не показывает.
