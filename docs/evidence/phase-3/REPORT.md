## Известные ограничения (ТЗ §16 п.8)

- VFR → CFR прокси (iPhone 29,997 fps → 30), синхронность звука в превью — 0 мкс (часть A).
- `confidence` у слов нет: воркер ASR его не отдаёт, в UI — «нет данных».
- Apple Vision — только macOS. Без него — режим `llm_only` с пометкой «уверенность низкая».
- Длинные ролики (> 6000 слов) — оконный смысловой анализ. Этот отрезок (≈ 420 слов) шёл одним окном.
- Ролик — один статичный шот, поэтому смену шотов эта приёмка не проверяет (её покрывают тесты Task 30 на нарезанной фикстуре).
