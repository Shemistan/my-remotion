   `evidence` остался прежним, а `videoSceneWindow` считает речь по `evidence`: продление (113,2–116,8 с
   ролика) — «хвост». Следствие: колонка «исходник» шпаргалки сцены 03 — один кусок 3,5 с из двух
   (кусок 174,37–177,97 с исходника отброшен фильтром `sourcePieces` по речи), хотя клип 7,2 с.
   Вероятно, и вход генерации (окно речи) берёт старое окно.
2. **SIGKILL рендера считается ошибкой кода сцены**: fix-loop тратит платный ход Engineer (≈ 1,5 мин)
   вместо повтора рендера. Результат верный, но дороже.
3. **В UI видеоплана нет правки границ сцены по словам** — только API (`modify start/end_word_id`).
4. **Пакет `regenerate` на несколько сцен — только API**: в UI перегенерация по одной плитке.
