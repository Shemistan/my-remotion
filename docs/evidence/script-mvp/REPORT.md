## Ход прогона и отступления

- run1–run3 — первый исполнитель: text, plan, edit, старт генерации. run4 (`MS_ACC_KEEP_SERVER=1
  MS_ACC_ONLY=generate,package-v1,refine,package,vertical,quality`) пережил смену исполнителя.
  Остановить его второму исполнителю не дал классификатор прав (`kill` чужого процесса, причина
  «Interfere With Workloads»), поэтому run4 доработал сам: generate ✓, package-v1 ✓, refine ✓,
  package ✘ (мягкий провал 13.9). После провала воркер перезапустился и упал (F13). run5 из
  worktree второго исполнителя: vertical ✓, quality ✓.
- Сервер 53153 запускал тест первого исполнителя. Второй остановил его `kill -TERM` для смены
  лимитов, а сервер 66136 с лимитами `7cc095f` — `kill -TERM` в конце приёмки.
- Evidence прошлых фаз (`docs/evidence/script-mvp/{s7,s10,s14,s15a,s15b,smoke-*,generate,overlay,ui}`)
  не перезаписаны.
- Поправки к спецификации теста во время прогона: опрос пакета через свежий `fetch` (F4). Запись
