# Ночной цикл качества (`./night`)

Одна команда на ночь: берёт пункты `docs/quality-backlog.md`, улучшает генератор в изолированной
ветке руками headless-агента Claude Code, принимает изменение только при росте оценки судьи на
bench, утром — отчёт с роликами. Спека — `docs/superpowers/specs/2026-10-23-night-quality-loop-design.md`.

## Запуск

Из worktree ветки задачи (не из main checkout), SSD подключён:

```sh
export MS_DATA_DIR="/Volumes/External SSD/MotionStudio"
./night --dry-run          # предпроверки и план: ничего не создаёт и не тратит
./night                    # до 07:00, бюджет $150
./night --until 06:30 --budget-usd 120
./night --smoke --until <ЧЧ:ММ> --item Q12   # проверка механики: 2+2 сцены, 1 итерация, дата <день>-smoke
./night --resume           # продолжить прерванную ночь (последнюю начатую, --smoke или --date)
./night --help
```

Запускать в обычном терминале. Mac не должен засыпать, а SSD — отключаться: `caffeinate -i ./night`.

## Что происходит

1. **Предпроверки** (и в `--dry-run`): `MS_DATA_DIR` с маркером хранилища; owner lock хранилища
   свободен (ADR 0007: не идёт bench, не запущен сервер); дерево без незакоммиченных правок
   отслеживаемых файлов; нет живой ночи на эту дату и живого агента прошлого запуска; `claude` в
   PATH; `./check` зелёный. Иначе — отказ с причиной, ничего не меняется.
2. **Изоляция**: worktree `<main>/.claude/worktrees/night-<дата>` (`git worktree add`), ветка
   `night/<дата>` от текущего коммита; `make install` в нём (npm ci + браузер рендера).
3. **Базовая линия**: принятый прогон из `docs/evidence/phase-1/bench/` на этом же коммите (оба
   набора, все сцены) или прогон ночи `night-<дата>-0-<sha>` (+`-user`).
4. **Итерация n**: верхний пункт со статусом `открыт` → ветка `night/<дата>-<n>` от последнего
   принятого коммита → агент (`claude -p` с брифом `scripts/night-brief.md`) → `./check` → bench
   explainer и user (`night-<дата>-<n>-<sha>`, `-user`) → правило приёмки
   (`server/src/bench/night-accept.ts`): explainer ≥ +0.1 и `--compare` «принять», user не ниже
   −0.2, failed не растёт, p90 стоимости ≤ $5, медиана времени explainer ≤ +25 %, все сцены
   оценены. Пункт со строкой `приёмка: без регрессии` роста не требует.
   - принято → `night/<дата>` fast-forward на итерацию, новая базовая линия, пункт `принято`;
   - не принято → ветка итерации остаётся, пункт `не дало роста: …` вниз списка;
   - сбой (таймаут/ошибка агента, нет коммитов, `./check` красный, bench неполный) → пункт
     `сбой: …` вниз списка, следующая итерация. Незакоммиченные правки агента — в `git stash`
     с меткой `night-<дата>-<n>` (не удаляются).
   Пометка пункта — коммит `docs(night): …` в `night/<дата>`; ветки пушатся в origin как копия.
5. **Остановка**: окно (`--until`, по умолчанию 07:00) не вмещает итерацию; бюджет (`--budget-usd`,
   по умолчанию 150) не вмещает итерацию; нет открытых пунктов; `--max-iterations`; выбранный
   `--item` пройден; SSD отключён (итерация остаётся в фазе bench, `--resume` её доведёт).

Ночь не удаляет и не переписывает ветки и коммиты, не трогает `main`, `staging` и основной
worktree, не меняет настройки и права. `docs/quality-backlog.md` меняется только в ветке ночи.

## Агент итерации

```
claude -p --output-format json --permission-mode dontAsk --permission-prompts none \
  --settings <main>/.claude/settings.json --max-budget-usd <$> --name night-<дата>-<n> < бриф
```

Права — те же, что у сессий проекта (его `settings.json`: `dontAsk`, sandbox, allow-список,
guard); запрос разрешения ночью некому подтвердить, поэтому он отклоняется и попадает в отчёт
(«блоки прав»). Лимиты на итерацию: время (`--agent-min`, 120; режется окном), деньги
(`--agent-usd`, 30; режется остатком бюджета). Агент не запускает bench и платные прогоны.

## Где что лежит

- `tmp/night/<дата>/state.json` — состояние (для `--resume`), `REPORT.md` — утренний отчёт
  (пересобирается после каждого шага), `<n>/brief.md`, `<n>/agent.json|err`, `<n>/check.log`,
  `<n>-bench-*.log`, `prepare.log`, `preflight-check.log`.
- `<worktree ночи>/tmp/bench/night-<дата>-<n>-*` — прогоны bench итераций.
- `<main>/tmp/motion-studio-examples/night-<дата>-<n>/` — ролики принятых итераций с README.

## Утром

Прочитать `tmp/night/<дата>/REPORT.md`, посмотреть ролики, `git log night/<дата>`. Влить в ветку
задачи после ревью: `git merge --ff-only night/<дата>`. Не принятые ветки `night/<дата>-<n>` — для
разбора; вернуть пункт в очередь — статус `открыт` в `docs/quality-backlog.md`.
